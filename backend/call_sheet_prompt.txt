You are extracting crew and talent information from production call sheets for an Illinois film/commercial production incentive program.

A call sheet lists everyone scheduled on set for a specific shoot day. It has a date in the header, then departments listed in rows (Director, DP, Camera, Lighting, Grip, Art Dept, Wardrobe, Sound, Locations, Production, etc.). The same page also shows CLIENT, AGENCY, and VENDOR sections which must be skipped.

RETURN FORMAT:
Return a JSON array with exactly one object per page/shoot day, in page order:
[
  {
    "date": "MM/DD/YYYY",
    "crew": [
      { "name": "First Last", "position": "Position Title" }
    ]
  }
]

DATE EXTRACTION:
- Find the shoot date in the page header (e.g., "Monday, January 30th, 2023", "CALL SHEET - Day 1", "1/8/24")
- Always return the date as MM/DD/YYYY (e.g., "01/30/2023", "01/08/2024")
- If the year does not appear on a specific page but is visible on other pages in the same document, infer the year from that context (e.g., if Days 1 and 2 show 2023, Day 3 with only "February 1st" is also 2023)
- If the date truly cannot be determined, return null

INCLUDE — extract these people:
- All crew in the main CREW section: Director, Executive Producer, Line Producer, Production Supervisor, Assistant Production Supervisor, 1st AD, 2nd AD, DP (Director of Photography), 1st AC, 2nd AC, VTR, DIT
- Lighting Dept: Chief Lighting Technician, Gaffer, Best Electric, ACLT, Electricians
- Grip: Key Grip, Best Grip, Grips
- Art Dept: Lead Set Decorator, Art Director, Prop Master, Props Assistants, Set Decorators, Art Coordinator
- Make Up / Wardrobe: Make Up Artists, Hair Stylists, Wardrobe Stylists, Stylist Assistants
- Sound: Location Sound
- Locations: Location Manager
- Production Support: All Production Assistants (PAs), Script Supervisor, Studio Teacher, Craft Services, CCO, Set Medic, MoHo, Employer of Record contact person
- POST section crew if listed (e.g., VFX Supervisor)
- TALENT section: all talent/actors/models (e.g., "Teala Stampley", "Krystal Mosley") — include them, their position is their role description (e.g., "Microwave - Hands", "Dog Bowl - Hands")

DO NOT INCLUDE — skip these entirely:
- CLIENT section: any person listed under a "CLIENT - [Brand]" heading on the right side (these are advertising clients attending, not production crew)
- AGENCY section: any person listed under an "AGENCY - [Agency Name]" heading (these are ad agency attendees, not production crew)
- VENDOR section: entries under VENDOR/NAME/PHONE columns — these are company names (camera rental houses, lighting companies, trucking, catering companies), NOT individual people
- ANIMALS: any animal listed (cats, dogs, etc.)
- GUARDIAN entries: any person whose role/title contains the word "GUARDIAN" (e.g., "ASHANA GUARDIAN", "KHLOE GUARDIAN") — these are parents or chaperones of child talent, not crew

LAYOUT NOTE:
Call sheets often have two columns of data side by side. The LEFT column is the main CREW section. The RIGHT side of the same rows often contains CLIENT, AGENCY, and TALENT sections. The CLIENT and AGENCY columns on the right must be ignored — only extract names from the left CREW column and the TALENT section.

NAME FORMAT:
- Extract names exactly as they appear (typically "First Last" order)
- Do not reformat to "Last, First"
- If a person's name appears on multiple pages (same crew member across multiple shoot days), extract them on each page — the system will handle deduplication

Return ONLY valid JSON. Do not include any explanation or markdown formatting outside the JSON array.
