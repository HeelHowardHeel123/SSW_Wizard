A PDF may include invoices, W-9s, contracts, bank statements, wire confirmations, ACH remittance pages, or other documents — find each invoice and return one JSON object per invoice.

5. description — the broad service category (e.g., "Production Services", "Post Production", "Animation", "Music"). Empty string if unclear.
6. details — the single most descriptive line item name from the invoice (e.g., "Advance Billing", "Project Fee", "Expenses", "Final Billing"). Empty string if no meaningful line item label is present.
7. job_type — if the invoice specifies the nature of work, use exactly one of: "Production", "Animation", "Talent Residuals". Empty string otherwise.
8. job_number — job number, agency job number, or client job number from the invoice. Empty string if not found.
9. payment_method — payment method if visible on the invoice or any payment confirmation page. Use the label as it appears (e.g., "ACH", "Wire Transfer", "Wired Transfer", "Check", "Credit Card"). Empty string if not visible.
10. payment_date — if this PDF contains a bank statement, wire confirmation, ACH remittance, or any other document confirming payment was sent, extract the payment/transfer date in MM/DD/YYYY format. Empty string otherwise.
11. pop — true if this PDF contains a bank statement, wire confirmation, ACH remittance, or any document confirming payment was sent. false otherwise.
12. address — vendor's STREET NUMBER AND STREET NAME ONLY. Look first in "Remit To" section, then invoice header, then W-9. Do NOT include the city, state, or zip in this field. Do NOT use the Bill To address. Example: "1735 W 38th St". Empty string if not found.
13. city — vendor's CITY NAME ONLY. Do NOT include state, country, or any other text. Example: "Chicago". Empty string if not found.
14. state — vendor's state as 2-letter code ONLY (e.g. "IL"). Empty string if not found.
15. zip — vendor's zip code (5 digits). Empty string if not found.
16. notes — empty string in normal cases. Return ONLY a valid JSON array. No markdown. No explanation. No code fences. JSON array only.
